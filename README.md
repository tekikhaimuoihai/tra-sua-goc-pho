# Trà Sữa Góc Phố

Game quản lý tiệm trà sữa chạy trên trình duyệt: pha đúng ly khách gọi (cốt trà, topping, lượng đường), mở khóa món mới, thuê nhân viên và nâng cấp quầy.

Chơi tại: GitHub Pages của repo này.

- Một file `index.html`, không cần build.
- Tiến độ lưu bằng `localStorage` của trình duyệt.
- Phím tắt: 1–6 cốt trà, Q W E R T topping, A S D đường, Space giao ly, X đổ ly, P tạm dừng.
